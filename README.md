## 项目

### [EchoMaze 回声迷宫](./EchoMaze)

一款 iOS SwiftUI 游戏：对着麦克风发声，声波"照亮"漆黑迷宫。

- **技术栈**：SwiftUI · AVAudioEngine · Canvas 渲染
- **目标平台**：iOS 17.0+（真机，需麦克风权限）
- **核心玩法**：6 种主题关卡，每种主题用不同的"音量→照亮"映射曲线，强迫玩家切换发声策略
- **进度**：陷阱、钥匙、暂停、最佳用时、设置、音效 / 触感反馈均已实现

详见 [EchoMaze/README.md](./EchoMaze/README.md)。
